# Fikstür formatı

Fikstürü bana aşağıdaki gibi gönder. Ben sisteme hafta hafta eklerim.
Sen yönetimden sadece **bonus seç + yayınla** yaparsın.

## Tek hafta örneği

```text
Hafta: 2025-26 28. Hafta

15.03.2026 19:00 | Fenerbahçe - Göztepe
15.03.2026 21:45 | Galatasaray - Beşiktaş
16.03.2026 16:00 | Trabzonspor - Başakşehir
16.03.2026 19:00 | Başakşehir - Göztepe
```

## Birden fazla hafta

```text
Hafta: 2025-26 28. Hafta
15.03.2026 19:00 | Fenerbahçe - Göztepe
15.03.2026 21:45 | Galatasaray - Beşiktaş

Hafta: 2025-26 29. Hafta
22.03.2026 19:00 | Beşiktaş - Trabzonspor
22.03.2026 21:45 | Göztepe - Fenerbahçe
```

## Kurallar

- Saatler **Türkiye saati**
- Sadece şu takımlar: Fenerbahçe, Galatasaray, Beşiktaş, Trabzonspor, Başakşehir, Göztepe
- Ev sahibi – Deplasman sırası önemli
- Bonus maçı sen seçersin (yüklerken işaretlemene gerek yok)
- Derbi (FB/GS/BJK/TS kendi aralarında) otomatik işaretlenir

## Akış

1. Sen fikstürü bu formatta yapıştırırsın (chat’e)
2. Ben veritabanına hafta + maçları eklerim
3. Sen Yönetim → ilgili hafta → bonus seç → **Haftayı Yayınla**
4. Maçlar bitince aynı sayfadan skor gir → **Puanları Hesapla**
